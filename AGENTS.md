# Agents

Project rules and commands for coding agents are in [CLAUDE.md](CLAUDE.md) (it applies
to every agent, not only Claude Code).

Task playbooks:

- **Start here** when the user asks what to do, how to begin or needs help setting
  Foriq up: [Getting started](docs/agents/getting-started.md) – lead them step by step
  from an empty Mac to counting sensors, running the commands yourself.
- [Fit stroke counting to a machine](docs/agents/tune-detector.md) – interview, settings,
  evidence, algorithm changes.
- [Port the firmware to another ESP32 board](docs/agents/port-hardware.md).

Claude Code also offers them as the project skills `/getting-started`, `/tune-detector`
and `/port-hardware`
(`.claude/skills/`).
